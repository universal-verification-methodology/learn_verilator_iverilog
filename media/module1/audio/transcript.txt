[Slide 23] 1. Directed functional testing. Vector tables: Apply known (sel, d0..d3) or (en, load) patterns; compare y or count Corner cases: Reset during operation, enable deasserted, all MUX select values Self-check: Inline if (expected !== actual) with error count and final summary Refer to the diagram on the right.

Test vectors: Read stimulus from files (file_io examples) for regression-style reruns Golden logs: Compare simulator output to expected transcripts where provided Orchestration: ./scripts/module1.sh runs example matrix; --check for CI-style gate Refer to the diagram on the right.
