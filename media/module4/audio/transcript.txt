[Slide 71] Next section: Common pitfalls.

[Slide 72] Mixing Concerns. Don't combine stimulus and checking in the same module/class Don't drive signals from monitor or checker components

[Slide 73] Hardcoded Values. Use parameters/constants for timing and configuration Avoid magic numbers in code

[Slide 74] Insufficient Checking. Don't rely on manual inspection of waveforms Always implement automatic checking

[Slide 75] Poor Error Messages. Include enough context to debug failures Use consistent error message format

[Slide 76] Inadequate Documentation. Document component purpose and interfaces Explain complex logic and timing relationships
