# Viewing Waveforms with GTKWave

This guide demonstrates how to view waveforms generated by iverilog testbenches using GTKWave.

## Prerequisites

- GTKWave installed: `./scripts/install_gtkwave.sh`
- iverilog installed: `./scripts/install_iverilog.sh`
- A testbench that generates VCD files (like `gtkwave_example.v`)

## Quick Start

### Automated Method

Run the provided script to compile, simulate, and open GTKWave:

```bash
cd module0/examples/iverilog_basics
chmod +x view_waveforms.sh
./view_waveforms.sh
```

### Manual Method

1. **Compile and run the testbench:**
   ```bash
   iverilog -o gtkwave_example gtkwave_example.v ../../dut/simple_gates/and_gate.v
   vvp gtkwave_example
   ```

2. **Open the VCD file in GTKWave:**
   ```bash
   gtkwave gtkwave_example.vcd
   ```

## Important: Adding Signals to Waveform Viewer

**GTKWave opens with the VCD file loaded, but signals are NOT automatically visible!**

You must manually add signals to the waveform viewer:

1. **Expand the hierarchy** in the left panel (SST - Signal Search Tree)
   - Look for `gtkwave_example` module
   - Expand it to see signals: `clk`, `a`, `b`, `y`, `enable`, `counter`
   - Also expand `dut` to see DUT signals

2. **Select signals** you want to view:
   - Click on signal names (e.g., `clk`, `a`, `b`, `y`)
   - Hold Ctrl/Cmd to select multiple signals

3. **Drag signals to waveform viewer**:
   - Drag selected signals from left panel to right panel (waveform viewer)
   - Or right-click and select "Send to Waveform"

4. **View waveforms**:
   - Signals should now be visible in the waveform viewer
   - Use zoom controls to examine timing

## Using GTKWave

### Basic Operations

1. **View Signals:**
   - Expand the hierarchy in the left panel (SST panel)
   - Select signals you want to view
   - Drag them to the waveform viewer (right panel)

2. **Navigate:**
   - **Zoom In/Out**: Use mouse wheel or zoom buttons
   - **Pan**: Click and drag in the waveform area
   - **Zoom to Fit**: Press 'f' or use the zoom-to-fit button

3. **Time Navigation:**
   - Use the time slider at the bottom
   - Click on a time value to jump to that time
   - Use arrow keys to move cursor left/right

4. **Signal Values:**
   - Hover over signals to see values at cursor position
   - Click on a signal to see its value in the status bar

### Keyboard Shortcuts

- `f` - Zoom to fit
- `z` - Zoom in
- `Z` - Zoom out
- `Left/Right Arrow` - Move cursor
- `Ctrl+F` - Find signal
- `Ctrl+S` - Save signal list
- `Ctrl+O` - Open signal list

### Saving Signal Lists (Creating .gtkw files)

You can save which signals are displayed for quick reloading:

1. Arrange signals as desired in the waveform viewer
2. Go to **File → Write Save File** (or press `Ctrl+S`)
3. Save as `gtkwave_example.gtkw` (same name as VCD file)
4. Next time, open with: `gtkwave gtkwave_example.vcd gtkwave_example.gtkw`

**This will automatically load your signal configuration!**

## Understanding the Waveform

### Signal Types

- **Binary signals** (single bit): Displayed as 0/1
- **Multi-bit signals**: Displayed as hexadecimal or decimal
- **Clock signals**: Usually square waves
- **Data signals**: Change based on logic

### Example: GTKWave Example Waveform

When viewing `gtkwave_example.vcd`, you should see:
- **clk**: Square wave clock signal (50MHz, 10ns period)
- **a, b**: Input signals changing over time
- **y**: Output signal showing AND operation result
- **enable**: Control signal
- **counter**: Integer counter value

## Troubleshooting

### GTKWave doesn't open

- Check if you have a GUI environment (X11 on Linux, macOS GUI)
- For headless systems, copy VCD file to a machine with GUI
- Or use remote X11 forwarding: `ssh -X user@host`

### No signals visible (most common issue!)

**This is normal!** GTKWave doesn't automatically add signals to the waveform viewer.

**Solution:**
1. Look at the left panel (SST - Signal Search Tree)
2. Expand the module hierarchy
3. Select signals and drag them to the right panel (waveform viewer)
4. Signals will then be visible

### VCD file appears empty

- Make sure VCD file was generated (`$dumpfile` and `$dumpvars` in testbench)
- Check that simulation completed successfully
- Verify VCD file is not empty: `ls -lh *.vcd`
- Check file size: should be > 0 bytes

### Can't see signal changes

- Zoom out to see the full simulation time
- Check simulation time in testbench
- Increase simulation duration if needed
- Make sure you've added signals to the waveform viewer

### Signals don't appear in hierarchy

- Check `$dumpvars` level in testbench
- Level 0 = all signals in module and below
- Level 1 = only direct signals in module
- Try: `$dumpvars(0, module_name)` to dump everything

## Creating Pre-configured Save Files

To avoid manually adding signals every time:

1. Open VCD file: `gtkwave gtkwave_example.vcd`
2. Add all desired signals to waveform viewer
3. Arrange them in preferred order
4. Save: **File → Write Save File** → `gtkwave_example.gtkw`
5. Next time: `gtkwave gtkwave_example.vcd gtkwave_example.gtkw`

The save file will automatically load your signal configuration!
