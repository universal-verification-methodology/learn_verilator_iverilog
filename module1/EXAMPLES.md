# Module 1 Examples

Hands-on examples for **iverilog Deep Dive**: compilation, simulation, testbenches, file I/O, waveforms, debugging.

---

## 1. Compilation (`compilation/`)

```bash
cd module1/examples/compilation
make basic_compilation
```

---

## 2. Simulation (`simulation/`)

```bash
cd module1/examples/simulation
make all
```

---

## 3. Testbench basics (`testbench_basics/`)

```bash
cd module1/examples/testbench_basics
make all
```

---

## 4. File I/O (`file_io/`)

```bash
cd module1/examples/file_io

```

---

## 5. Waveforms (`waveforms/`)

```bash
cd module1/examples/waveforms

```

## 6. Debugging (`debugging/`)
